# MediaDock

A Windows desktop app for downloading and organizing Instagram, YouTube, and TikTok media.

This repository contains public app releases and signed update metadata. Existing installations download and verify releases through **Tools & updates** in MediaDock.

[Latest release](https://github.com/josephacastiglia/mediadock-releases/releases/latest)

Releases use an Ed25519-signed update manifest and SHA-256 file verification. This is app update verification, not a Windows Authenticode certificate.
